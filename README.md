# Wei Xian — Technical Profile

Source for [elystra-v.github.io](https://elystra-v.github.io), Wei Xian’s
evidence-led technical profile.

The site focuses on engineering capabilities, tools, practices, and Kinesema as
real system context. It is intentionally separate from Kinesema Labs’ business
and product website and avoids vanity metrics or self-promotional portfolio
conventions.

## Preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Scope

- `index.html` — technical profile homepage
- `work/kinesema/index.html` — public engineering case study
- `404.html` — accessible recovery page
- `styles.css` — shared responsive styles
- `favicon.svg` — simple WX site mark

The Kinesema business domain remains separate. Private source and unreviewed
prototype material are not published here.
